# Security Policy

## Supported Versions

| Version | Supported |
| ------- | ------------------ |
| v1.2.x | :white_check_mark: |
| < 1.2 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability within Time-Travel Debugger MCP, please report it privately:

1. Open a confidential security advisory on GitHub or contact the maintainer.
2. Provide a detailed description of the vulnerability and steps to reproduce.
3. We will acknowledge receipt within 48 hours and provide status updates as we resolve the issue.

Thank you for helping keep Time-Travel Debugger MCP secure!
